## Project Overview [![Sensum](https://wakatime.com/badge/github/martinjanas/Sensum.svg?style=plastic)](https://wakatime.com/badge/github/martinjanas/Sensum)

This project is being actively developed.<br>
Expect things to be half-done or in progress, menu is still in work in progress stage.<br>
Config system is not finished, but works, but if you wish to not overwrite your config make sure to load the config only in game (still have to make weapon selection widget)<br>


  **Note:** Click the **Sensum "logo"** to display hidden options (for now, only applicable when the menu is a work in progress).
![Reference](https://i.imgur.com/N3FImsv.png)

<details>
  <summary>Features:</summary>
  
  - Aimbot:
    - Distance based fov (distance) to be exact, 20 distance is roughly 2.5 degree fov in p2c aimbots.<br>
    - Smoothing:
      - Linear
      - Constant
      - Lerp (currently partially broken), but works.<br>
    - Recoil Control System:
      - Pitch & Yaw
      - Fov Based/standalone
    - Hitboxes/hitbox groups:
      - Head
      - Body
      - Arms
      - Legs
      - Nearest in air (Selects nearest hitbox when target player is in the air)<br>

  - Esp/visuals (in wip stage):
    - Visible only
    - Bone esp
    - Box esp
    - Box fill (experimental)
    - Name esp
    - Player weapon icon esp (wip)
    - Dropped weapons icon esp (wip)
    - Grenade icon esp
    - Smoke timer (wip)
    - Bomb timer & bomb icon (wip)
    - Player Chams (wip), currently drawing team players as well, because im not chamming players, but materials, to be fixed hopefully later.
    - Chams material creation (wip)
   
    - Misc:
      - Bhop (is probably detected when enabled)
      - Unhook
      - Save & Load config (in wip stage, only load config in game, or you risk overwriting your config)
</details>
